# Engineering writing

Write for humans with concrete evidence.

Use for:

- PR titles and bodies
- commit messages
- implementation notes
- findings
- handoff summaries
- release notes
- docs or README changes

Rules:

- state what changed
- state why it changed
- back verification claims with evidence
- name risks and caveats plainly
- avoid vague confidence
- avoid filler and generic AI phrasing
- preserve the project's voice
- do not rewrite untouched prose

If a sentence could fit any project unchanged, make it specific or remove it.
