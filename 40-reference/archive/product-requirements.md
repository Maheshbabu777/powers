# Product requirements

Turn vague requests into buildable specs.

Produce:

- user problem
- goal
- scope
- non-goals
- user journey
- acceptance criteria
- accessibility requirements
- loading, empty, error states
- open questions

Never invent a requirement. Ambiguity becomes an open question or a human clarification.
