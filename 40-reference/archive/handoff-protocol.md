# Handoff protocol

No material decision may exist only in conversation.

Every handoff states:

- input artifact consumed
- output artifact produced
- current risk level
- current gate
- evidence attached
- open questions
- known limitations
- next owner

## Backward handoff

Use a structured Finding when rejecting work. Send it to the owning role.

## Forward handoff

Use a sign-off bundle when passing work forward. Include evidence and caveats.

## Missing contract

If you need another role's private instructions to continue, the public handoff contract is underspecified. Raise that as a finding instead of reading unrelated files.
