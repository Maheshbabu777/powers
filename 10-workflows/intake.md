# Task intake

Produce or update a task record before real work starts.

Decide:

- task type
- whether requirements are clear
- likely risk level
- affected areas
- required source-of-truth artifacts
- current workflow
- next handoff

Ask the human when ambiguity changes scope, cost, data exposure, security, or irreversible operations.
